# Synthetic PaySim drift data provenance

This file is a weighted bootstrap of complete rows from the project's prepared, labelled PaySim V2 dataset. `isFraud` is inherited from each referenced source row; it is not an independently verified outcome. No feature values were edited. Source event IDs are included for audit. See `synthetic_drift_data_config.json` for seed, row counts, source hash, and weighting settings.
